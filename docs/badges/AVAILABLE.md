# Artifacts Available

1. Open the repository: https://github.com/K1015/PAC-Certification-of-Multivariate-Side-Channel-Traces. It is public; no account is needed.
2. Open [`LICENSE`](../../LICENSE): the code is under the MIT license.
3. Open the release [v1.0](https://github.com/K1015/PAC-Certification-of-Multivariate-Side-Channel-Traces/releases/tag/v1.0). It holds the trained models used in the paper, `bi_certification_checkpoints.tar.gz` (308 MB).
4. Open [`datasets/README.md`](../../datasets/README.md): it lists every public trace set and the script that downloads it.
